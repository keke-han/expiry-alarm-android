## 已知边界

- 数据只保存在本机，支持用户主动导出和恢复 JSON 备份，不提供自动云同步。
- 提醒是日级检查，不是分钟级精确闹钟，可能受通知权限、系统省电和强行停止影响。
- 当前文字输入和界面只支持中文。
- APK 约 82MB，主要来自内置离线中文语音模型；本版本未申请 `INTERNET` 权限。
- 语音识别只面向中文。英文名称请键盘输入；用户必须核对识别结果后再添加。
- 荣耀真机已通过屏幕关闭、深度待机后的系统定时唤醒通知；不同品牌的省电策略仍需分别验证。
- 荣耀需在“应用启动管理”中改为手动管理并允许自启动、关联启动和后台活动；开启后重启恢复提醒已通过。
- Android 13 / API 33 通知权限的首次授权、拒绝、允许和系统关闭后状态已通过官方模拟器验证，尚未做 Android 13+ 真机验证。
