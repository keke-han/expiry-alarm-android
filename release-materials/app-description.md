# 到期闹钟

开发者：韩永亮

反馈邮箱：achilles042178@outlook.com

## 一句话简介

一句话记录到期事项，提前提醒少忘事。

## 应用介绍

做「到期闹钟」，是想把生活里那些不常发生、却容易忘记的到期事项，放在一个简单的地方。

护照什么时候到期，会员哪天结束，食品还能放多久，不想每次都填一堆表格。

输入“护照2029年5月10日到期，提前90天、30天和7天提醒”，应用就会识别事项、到期日期和多个提醒时间，确认后保存。也可以使用内置离线中文模型进行语音输入。

不需要注册账号，文字解析和记录存储在本机完成。首页提供待处理、30天内、已过期和已处理概览，支持证件、卡片、会员、食品和纪念日快捷添加。事项可设置多个提醒点，到期后可标记已处理或续期，并保留历史到期日期。

支持搜索、状态筛选、列表和按月日历视图；生日、纪念日等事项可设置每年重复。设置中可导出或恢复本地备份，无需开通云同步。支持浅色、深色和跟随系统，也可以设置默认提前天数和每日提醒时间。

目前是个人开发的早期版本，先把记录和提醒这两件事做好。欢迎把遇到的问题和真实使用感受告诉我。

使用前请了解：

- 只输入年和月时，会按该月最后一天作为到期日；仅输入月份但没有年份时不会自动猜测。
- 提前“1个月”按30天、“1年”按365天计算。
- 每天检查需要提醒的事项，属于日级提醒，不是分钟级响铃闹钟；通知权限、系统省电、自启动限制和强行停止应用都可能影响提醒，部分品牌需要在系统中允许应用自启动和后台活动。
- 语音输入只面向中文，英文名称请使用键盘输入；语音结果可能存在误差，请核对后再添加。首次启动离线识别可能需要等待几秒。
- 本版不提供账号或云同步。卸载应用或清除数据会删除记录，换机前请在设置中导出本地备份。

- 新增证件、卡片、会员、食品和纪念日分类与快捷添加。

## 0.1.4 更新说明

- 新增事项搜索、30天内和已过期筛选。
- 新增列表与按月日历视图。
- 新增每年重复提醒，可在一句话中输入“每年”或在编辑页设置。
- 首次启动增加隐私政策确认，用户同意前不申请录音和通知权限。
- 完善录音用途、处理范围、本机识别和数据保存说明。

## 0.1.3 更新说明

- 改进本地离线中文语音识别，不依赖系统语音服务。
- 支持只输入年和月，自动按当月最后一天记录。
- 支持“六个月”、“陆个月”、“半年”、“一周”等中文提前提醒表达。
- 支持语音识别返回的中文数字日期。
- 支持日期使用口语“号”，并修正“保质期到”等事项名称解析。
- 识别到未知语音内容时会提示重试，不生成含未知标记的事项。

大家好，我是韩永亮，做了一个简单的到期提醒工具，叫「到期闹钟」。

日常有不少事情不需要天天记，却很容易等到过期才想起来：证件、会员、食品保质期……我想做的就是把记录这一步变简单。

写一句“护照2029年5月10日到期，提前3个月提醒”，确认一下就能保存。不用注册账号，数据留在手机上。

现在还是早期版本，功能不多，主要是记录、提前提醒、编辑和删除。提醒会受到手机通知权限和省电设置影响，还在持续做不同机型的测试。
