# 到期闹钟 APK 测试说明

## 安装方式

1. 把 `app/build/outputs/apk/release/app-release.apk` 发送到安卓手机。
2. 在手机上点开 APK。
3. 如果系统提示禁止安装，进入设置里允许当前来源安装应用。
4. 安装完成后打开“到期闹钟”。
5. Android 13 及以上系统首次打开时允许通知权限。

## 测试输入

```text
护照 2029-05-10 提前3个月提醒
Netflix 2026年7月20日到期 提前7天提醒
身份证 2030年1月1日到期
护照 2028年7月到期 提前6个月提醒
护照 2028年7月8日到期 提前六个月提醒
护照 2028年7月8日到期 提前陆个月提醒
护照 2028年7月8日到期 提前半年提醒
```

## 必测场景

- 首次安装 APK。
- 覆盖安装新版 APK。
- 无网络状态下新增、编辑、删除记录。
- 通知权限关闭时不会弹提醒。
- 通知权限开启后可收到到期前 N 天和到期当天提醒。
- 手机重启后每日检查仍会重新调度。
- 首次点击麦克风时允许录音权限，等待离线模型准备完成后说出完整提醒事项。
- 没有系统语音服务时，语音仍能离线识别并回填到输入框。
- 录音权限被拒绝时，应用不闪退，文字输入仍可使用。
- 断开网络后语音识别仍可用。

## 设置验收（待真机验证）

- 默认跟随系统，分别切换浅色、深色；检查主页、设置、编辑弹窗、时间选择器的文字与背景。
- 退出并重开应用，确认主题、默认提前天数、每日提醒时间仍保留。
- 默认天数改为 7，输入“身份证2030年1月1日到期”，确认解析为 7 天；已有记录保持原值。
- 输入“护照2029-05-10提前3个月提醒”，确认明确的提前时间优先于默认设置。
- 默认天数允许 0–3650；空白、负数和超范围数值不能保存；取消编辑不改变设置。
- 提前 0 天的事项在到期日只发送一次“今天到期”通知。
- 修改每日提醒时间后确认调度更新，重启手机后仍使用该时间。调度不保证分钟级精准，系统省电可能延迟。
- 从设置进入系统通知页面，分别关闭应用通知、关闭“到期提醒”通知渠道，再返回检查“未开启”状态。
- 重新启用通知，返回应用检查“已开启”，点击“发送测试通知”，在通知栏检查并点击打开应用。
- 测试通知成功不代表后台定时提醒可靠；仍需关屏、省电和应用关闭场景的独立测试。
- 浏览器预览只演示主题和设置交互，不能验证安卓通知。

## 签名注意

`keystore/` 目录里的签名文件和密码文件只用于本地测试，不要上传到公开仓库。后续覆盖升级必须继续使用同一个 keystore，否则 Android 会要求先卸载旧版。
