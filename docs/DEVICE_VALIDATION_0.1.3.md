# 0.1.3 设备验证记录

设备：荣耀 JSN-AL00a 真机、Android 13 / API 33 官方模拟器。日期：2026-09-09。

## 已验证

- 0.1.3（versionCode 4）覆盖安装、启动成功。
- APP 内语音：一次将“到期”误识别为“到7”；重复测试正确识别“护照2028年7月8日到期提前半年提醒”。不能以重试成功抹去首次错误。
- 正确语音结果解析为护照、2028-07-08、180天；保存并强制停止后重新启动，记录仍保留。
- 年月输入采用月末；陆个月、六个月、半年均解析为180天。
- 口语“20号”已修复并复测：识别为信用卡、2027-11-20、提前30天。
- “提前一周”已修复并复测：识别为妈妈生日、2027-05-20、提前7天，不再混入事项名称。
- “奈飞会员”中文语音识别为奈飞会员、2026-07-20、提前7天。
- 英文“Netflix”不在当前中文语音模型能力范围内。显式未知标记会被拦截；模型也可能直接漏掉英文，因此英文名称必须键盘输入并人工核对。
- 独立测试记录的新增、修改名称/日期/提前天数、重新打开核对、删除后重新打开核对全部通过。仅清理测试创建的记录。
- 主动触发生产 ReminderReceiver：当天到期与提前7天通知均出现。此项不等同于后台定时触发。
- APP不在前台、屏幕关闭并强制进入深度待机后，系统按登记闹钟自动唤醒并发出“今天到期”通知；测试事项和通知随后已清理。
- 荣耀“应用启动管理”采用自动管理时，系统会将开机接收器标记为 `Skipped`，重启后不会自动恢复提醒。
- 改为手动管理并开启允许自启动、关联启动和后台活动后再次重启；未手动打开APP，系统约120秒后自动恢复每日09:00提醒。
- Release APK 覆盖安装、v2 签名和权限清单已复核；未申请联网权限。
- 已重新截取荣耀真机列表、编辑、深色主题和设置页面，截图不再含内部测试事项。
- Android 13 / API 33 官方模拟器已验证：首次安装会弹出通知授权；拒绝时不发通知；允许后测试通知成功；系统中再次关闭权限后，APP 能显示“未开启”并阻止发送。

## 待验证与限制

- 更多中文语音说法、自然停顿、连续录音和噪声下的表现。
- 麦克风拒绝权限、录音期间退后台、无声录音结束。
- Android 13+ 通知权限已通过官方模拟器验证，尚未在 Android 13+ 真机上验证。
- 小米/OPPO/vivo 等其他品牌真机兼容性测试按当前阶段决定暂缓，不作为本次提交的阻塞项。
- 每日任务已改为 `setAndAllowWhileIdle` 单次调度并在触发后安排下一天。荣耀系统显示09:00任务最晚窗口约为当日21:00；这仍不是实际待机送达测试，也不保证分钟级准点。
- 半年目前按180天计算，不等于严格的六个自然月。

结论：荣耀真机单机核心流程、深度待机定时通知和开启自启动后的重启恢复均已通过；Android 13 通知权限流程已通过官方模拟器验证。其他品牌真机的后台和省电策略仍是未覆盖风险，按当前阶段决定暂缓。
